Sky Text is Sky's proprietary typeface and isn't included. Add the licensed
web font files here (from the Sky brand team) with these exact names:

- SkyText-Regular.woff2         — Sky Text, weight 400 (body, subtitles)
- SkyText-Medium.woff2          — Sky Text, weight 500 (labels)
- SkyTextHeadline-Medium.woff2  — Sky Text Headline, weight 500 (headlines)

Without them, a machine with Sky Text installed uses that copy; otherwise the
slides fall back to the system sans-serif.
